## 🏢 Featured Lab Blueprint — Three-Department Office Network

A practical enterprise-style scenario I am preparing to implement and document.

| Department | VLAN ID | Example subnet |
|---|:---:|---|
| Administration | 10 | `192.168.10.0/24` |
| Accounts | 20 | `192.168.20.0/24` |
| IT | 30 | `192.168.30.0/24` |

**Implementation plan**
1. Create VLANs and assign switch access ports.
2. Configure trunk links between network devices.
3. Configure inter-VLAN routing.
4. Provide client addressing through DHCP.
5. Apply ACLs to restrict selected inter-department traffic.
6. Verify connectivity and document successful and failed test cases.
